## Summary

Converts the shop to pickup-only ordering, moves SMS dispatch to queued jobs, and addresses two security vulnerabilities found during security review.

## Changes

### Pickup-Only Ordering
- Removes `delivery_type`, `delivery_address`, `delivery_date` from orders schema, models, controllers, tests, and all frontend components
- Renames `delivery_date` → `pickup_date` across the entire stack
- UI: removes address input, delivery/pickup toggle, delivery address display — all orders are store pickup

### Queued SMS Notifications
- New `SendStatusUpdateSMS` job with 3 retry attempts and exponential backoff (10s, 30s, 60s)
- Dedicated `sms` queue connection in `config/queue.php`
- New `config/sms.php` gateway configuration supporting httpSMS and TextBee with dynamic driver selection
- `NotificationService::sendSmsDirect()` replaces deprecated `dispatchSms()`/`logSmsFailure()`
- SMS logs now track `order_id` FK and `attempts` for job-aware auditing

### Security Fixes
- **SSL verification bypass removed**: `$request->withoutVerifying()` removed from both httpSMS and TextBee gateway calls
- **Authentication enforced on order creation**: guest checkout removed — returns 401 if no authenticated user
- **Defensive auth checks added**: `submitPayment()` and `cancel()` now check `$request->user()` before accessing `->id`

### Other
- Removes `same_day_delivery` setting from admin panel and API
- Updates seeders with realistic PHP pricing and consolidated user accounts
- Adds cross-user payment rejection test
